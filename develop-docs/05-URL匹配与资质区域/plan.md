# 任务 5：URL 匹配与资质区域开发计划

## 目标

在资质提交页面的“URL状态概览”区域中，按 `url.txt` 清理后的 URL 找到对应行，点击该行的“查看”，并确认“行业资质”区域成功加载。

## 实现步骤

1. 接收任务 1 的 `url` 和任务 4 已完成跳转的页面。
2. 等待“URL状态概览”标题和表格出现。
3. 读取表格中每行的 URL 列文本。
4. 使用清理后的输入 URL 与页面 URL 文本进行精确匹配。
5. 在匹配行内部定位“操作区”的“查看”按钮，禁止直接点击页面中第一个“查看”。
6. 点击该行的“查看”；“信息资质状态”仅作展示，不作为阻断条件。
7. 等待资质内容加载。
8. 以页面出现“行业资质”标题/区域作为成功标志。
9. 输出当前公司、URL、匹配结果和页面状态，交给后续资质表单任务。

## 匹配规则

- 输入 URL 在任务 1 中已移除空格、换行和制表符。
- 页面 URL 只按页面展示值进行精确匹配，不自动删除查询参数、修改协议或忽略路径。
- 如果后续确认页面存在尾部斜杠或其他统一差异，再单独增加规范化规则；当前不做模糊匹配。
- 找不到匹配行或匹配多行都视为业务错误。
- 匹配行即使显示“待审核”也进入详情；后续由流程 6 根据行业资质区域实际存在的编辑、删除和新增入口决定能否安全处理。

## 分页和加载

- 首先处理当前页。
- 如果页面显示分页且当前页没有匹配项，应按页查询，直到找到匹配项或遍历完毕。
- 表格可能是异步加载，不能仅依赖页面初始 HTML。
- 点击后等待“行业资质”区域，而不是只等待固定时间。

## 验收标准

- 能找到截图中红色标注的 URL 列内容。
- 能点击同一行的“查看”按钮。
- 不会误点击其他行的按钮。
- URL 不存在、重复或分页遍历失败时有明确错误。
- 点击后能确认“行业资质”区域出现。
- 本任务不填写、不上传、不点击表单“提交”。
