# 失败后延迟关闭浏览器

目标：按用户要求，出现错误时让可见浏览器保留5秒再关闭，便于查看页面。
范围：BrowserSession统一异常退出，覆盖主登录和公司worker；正常成功立即关闭。
设计：异常清理前判断是否存在仍打开的可见页面，记录“发生错误，5秒后关闭浏览器”，等待5秒再执行原有清理。不打印异常原文，避免认证信息泄露；没有浏览器窗口、已手工关闭或无头测试不等待。等待异常不覆盖原始业务错误。
步骤：补充统一错误关闭处理；用模拟会话验证时序和分支；运行浏览器与worker回归。
依赖：任务2、9；与任务56同时完成，无新增依赖。
验收：可见窗口异常退出先等5秒后关闭且保留原异常；成功不延迟；无窗口/已断开不额外等待；worker仍关闭Chrome并记录失败。
不在范围：暂停后继续、自动重试、修改用户输入、打包发布。
状态：完成，未打包发布。
验收：8项模拟会话用例确认等待恰好5秒、先等待后关闭、正常成功和无窗口不延迟、等待异常不覆盖业务错误。已包含在本次70项浏览器/应用/查询回归中，全部通过；未执行Windows可见窗口人工验收。
