# 测试用例

## Windows PID

1. Windows 分支调用专用无损查询函数，不调用 `os.kill`。
2. Windows API 返回等待超时时判定进程存活。
3. Windows API 返回已结束时判定进程不存在。
4. POSIX 分支继续使用信号 0。

## 登录

1. 已登录页面直接保存状态。
2. 人工确认后识别到已登录页面再保存状态。
3. 人工确认后仍为登录页，抛出认证错误且不保存状态。
4. 桌面提示不再包含“按回车”。

## 运行结果

1. 有业务失败时显示失败。
2. 有 busy 公司时显示未处理，不显示全部成功。
3. CLI 在 failures 或 busy 非空时返回非零退出码。
4. 已完成去重公司不视为 busy。

## 日志

1. 首次读取显示全部已有日志。
2. 后续读取仅显示新增日志。
3. UTF-8 字符跨两次读取时不产生乱码。
4. 日志截断或替换后能重新开始读取。

## 取消

1. 登录等待期间取消立即退出。
2. 公司执行期间取消，当前公司完成后停止后续公司。
3. 未开始公司状态写为 `task-cancelled`。
4. 关闭窗口时可请求安全取消并在结束后关闭。

## 打包

1. 源码入口执行 `--self-check` 成功。
2. Windows 和 macOS 冻结产物执行 `--self-check` 成功。
3. self-check 不启动 Chrome、不访问真实接口。
