# 移除“待审核”状态提前拦截计划

## 目标

不再根据“URL状态概览”中的“信息资质状态”为“待审核”提前跳过公司。匹配到目标 URL 后始终进入“行业资质”详情，并以详情页实际提供的编辑、删除和新增能力决定能否执行整类覆盖。

## 问题背景

百度概览表展示的“待审核”状态不能可靠反映行业资质是否可操作。当前逻辑在点击“查看”前直接抛出 `qualification-pending-review`，会错误跳过实际可以编辑或删除资质的公司。

## 范围

- 删除目标 URL 行的“待审核”提前拦截。
- 移除只服务于该拦截的异常类型和错误码测试。
- 保留 URL 精确匹配、唯一行校验和行内“查看”定位。
- 保留流程 6 在任何修改前执行的详情页能力预检。
- 更新当前项目规范、流程 5 文档和自动化测试。
- 发布版本统一升级到 `0.30.6`。

## 设计

1. 匹配到唯一 URL 行后直接点击该行“查看”。
2. 等待“行业资质”区域出现。
3. 扫描经营业务和资质卡片。
4. 在修改前验证计划涉及的删除业务、删除资质、编辑首卡、备用资质上传和新增业务入口；入口必须唯一、可见且未被禁用。
5. 页面实际缺少必要操作入口或结构无法安全区分时，沿用明确的 `PageFlowError` 停止当前公司；预检通过则继续原处理逻辑。

- [x] 可编辑或可删除的资质按原逻辑处理。
- [x] 实际缺少必要编辑、删除或新增入口时才报错。
- [x] 不再产生 `qualification-pending-review`。
- [x] 定向测试和完整测试通过。

- 不修改单项资质提交和最终 `submitall` 规则。
