# 测试用例

## URL 概览

1. 目标 URL 唯一且状态为“待审核”：点击同一行“查看”，等待“行业资质”出现，不提前报错。
2. 目标 URL 唯一且为其他状态：保持原有进入详情行为。
3. URL 不存在或重复：保持原有明确错误。

## 详情页能力预检

1. 已有资质可删除：验证删除目标后允许继续处理。
2. 唯一不可删除首卡可编辑：验证编辑入口后允许覆盖。
3. 不可删除首卡无编辑入口：详情页预检报错，且不执行修改。
4. 多个不可删除已填卡：因无法安全覆盖而报错。
5. 需要新增资质但无备用上传入口：详情页预检报错。
6. 编辑入口可见但具有 `disabled`、`aria-disabled`、禁用类或禁用祖先：详情页预检报错。
7. 删除入口可见但具有 `disabled`、`aria-disabled`、禁用类或禁用祖先：详情页预检报错。

## 回归

1. 不再引用 `QualificationPendingReview` 或 `qualification-pending-review`。
2. 流程 6 仍在任何修改前完成全部能力预检。
3. 完整测试通过。
4. `git diff --check` 通过。

## 验证结果

- 定向测试：26 项通过。
- 完整测试：87 项通过。
- “待审核”进入详情和详情页不可编辑/不可删除报错场景均已覆盖。
- 可见但禁用的编辑、删除入口均在修改前被预检拒绝。
