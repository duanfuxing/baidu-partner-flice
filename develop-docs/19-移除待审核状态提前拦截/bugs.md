# 问题记录

## BUG-001：“待审核”概览状态错误阻断可编辑资质

- 状态：已修复
- 复现条件：目标 URL 的“信息资质状态”显示“待审核”，但进入详情后资质实际仍可编辑或删除。
- 现象：程序在点击“查看”前抛出 `qualification-pending-review`，未检查真实操作能力。
- 原因：把概览展示状态等同于详情页编辑权限。
- 解决方案：移除概览状态拦截，以详情页操作入口预检结果作为处理依据。

## BUG-002：可见但禁用的操作入口被预检误判为可用

- 状态：已修复
- 复现条件：行业资质详情页渲染编辑或删除控件，但控件自身或祖先处于禁用状态。
- 现象：预检只判断 `is_visible()`，错误放行；实际处理可能在已删除其他资质后才点击失败。
- 解决方案：统一判断操作控件的可见性、启用状态、禁用属性、禁用类和指针事件，并增加禁用入口回归测试。
