# 测试用例

## 桌面界面

1. 任务中心不再显示 dry-run 和失败截图选项。
2. 显示“完成后执行全部提交”，初始状态未勾选。
3. 忙碌状态下最终提交选项不可修改，任务结束后恢复。
4. 确认运行时分别显示“执行最终提交”和“仅完成资质填写，不执行最终提交”。

## 工作流

1. `final_submit=True` 且所有单项成功：调用 `submitall`，最终提交标记为成功。
2. `final_submit=False` 且所有单项成功：不调用 `submitall`，任务正常结束，最终提交标记保持为假。
3. 任一单项失败：无论开关状态均不调用 `submitall`。
4. 未最终提交的运行可再次领取，不能被当作已经送审完成。

## 回归

1. 命令行 dry-run 和失败截图参数继续可用。
2. 输入验证、登录、取消、日志和单 worker 行为不变。
3. 完整 pytest、PyInstaller 构建和冻结包 self-check 通过。

## 验证结果

- 定向测试：19 项通过。
- 完整测试：70 项通过。
- PyInstaller macOS Intel 应用包：构建通过。
- 冻结应用 `--self-check`：通过。
- 新版应用实际启动：通过。
