# 上传成功未回填补传

目标：解决0.30.11上传成功且等待回填超时、条目未出现时直接停止的问题；按用户要求允许额外补传一次。

设计：成功请求结束后确认当前列表仍只有原成功文件；核验原文件ID、内容、加载状态稳定及新上传凭据有效且未占用原ID；不存在可删项时不点击删除。每张文件只允许一次缺失补传，计入总重试上限；补传前再次检查数量，迟到回填、重复、请求不确定或原图变化时停止。
依赖：现有Playwright和上传凭据，无新增依赖。
