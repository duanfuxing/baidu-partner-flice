- 新增后等待新增卡片数量和容器稳定，核对原业务编号仍存在；记录新增数量。
- 有原业务时仍只允许新增一个；出现多张即停止，不猜测。

- 从后向前删除非目标空卡，每次重新按目标类型扫描，处理编号变化；保留唯一目标后继续正式上传。
