# 任务 60：新版资质完整网络链路采集

## 目标

从选择第一个文件前开始，持续观察单个资质目录全部文件上传、保存、回填及重新打开后的持久化结果，依据真实证据评估页面操作与接口提交。

## 范围与设计

- 使用项目专用 Playwright / Chrome 和已保存登录状态，复现项目当前真实行为，不控制日常个人资料。
- 独立诊断脚本，不修改正式上传及调度逻辑；先检查页面已有数据，再执行单目录采集。
- 网络记录涵盖浏览器上下文内请求、响应、完成、失败及业务 JSON 结构；关联页面事件、卡片快照、主动保存和稳定性检查。
- 动态标识以本次采集内一致的匿名代号关联；认证字段丢弃，其他自由文本脱敏。不写原始 HAR、Cookie、Token、完整请求头、截图及文件内容。
- 只操作明确选定的一张资质卡片；已有数据需确认处理方式，不擅自删除其他业务或资质。最终 submitall 始终拦截。

## 步骤

1. 建立脱敏采集器与独立诊断入口，先离线验证隐私过滤和请求时序。
2. 打开输入公司详情，核对样本卡片和登录状态。
3. 对一个多文件目录记录完整实际上传，继续等待保存和回填，重新打开验证持久化。
4. 输出实际时间线、接口依赖、完成条件及两种实现方式的评估，严格区分观察与推断。

## 依赖

任务 53、55、59；沿用现有 Playwright、pytest 和标准库，不新增依赖。
