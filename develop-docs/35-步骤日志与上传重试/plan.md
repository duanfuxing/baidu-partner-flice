# 任务 35：步骤日志与上传重试

## 目标与范围

输出业务类型、资质目录、文件及动作日志。上传失败先核对当前卡片文件数量变化，确认没有新增文件才重试，首次失败后最多重试 3 次（最多 4 次上传）。

## 设计与步骤

提取共享上传控制器；监听本次精确上传请求的响应和失败，避免跨次响应错配。以当前卡片已上传预览为依据，不能用 input.files 证明上传成功。上传结果不确定、请求仍未结束、部分成功时停止，避免重复。成功响应但预览延迟时继续等待；接口响应缺失但预览已新增时不重复上传。旧版需服务端文件 ID，缺少成功凭据时停止而不重传。

补充导航、业务增删、卡片准备、文件上传/核验/重试、举证链接、自动保存及最终校验/送审日志。日志不包含动态 URL、认证信息或请求体。

## 依赖

任务 6、23、33；无新依赖。

## 验收标准

本地页面测试覆盖失败重试后成功、耗尽 3 次重试、已存在不重复上传、延迟回填、未知状态不重试、监听器清理；日志能定位业务/资质/文件。真实接口不用于自动测试。

## 不在范围内

不重试 submitlice/submitall，不自动重跑整家公司，不发布。

## 验收结果

已完成。页面夹具共 46 项通过（完整回归 45 项中旧版域名夹具修正后单项复验通过，另加未完成请求保护 1 项通过）。相关非浏览器回归通过。当前文件卡片不能确认或请求仍执行时停止；只对明确缺失且请求结束的上传重试，首次加 3 次重试。未连接真实送审接口。
