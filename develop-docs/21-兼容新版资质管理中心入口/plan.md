# 任务 21：兼容新版资质管理中心入口

## 状态

已完成代码与本地页面夹具回归；新版真实登录页面待下一次业务运行验收。

## 目标

兼容 `qulificationAuditUrl` 打开后跳转到百度新版资质统一管理中心的流程。在新版首页中，准确点击“资质信息审核”卡片内的“查看”，进入“URL状态概览”；同时保留旧版“资质环节”入口。

## 范围

- 识别 `fkzhunru.baidu.com/newaudit#/lice/...` 新版管理中心 URL。
- 以“资质信息审核”标题为作用域，点击同一卡片内唯一可见的“查看”。
- 避免误点“真实性认证”等其他卡片的同名“查看”。
- 进入后仍以受支持的 URL 和“URL状态概览”共同判断成功。
- 保留旧版 `/flice#/truth/submit...` 及“资质环节”流程。
- 更新流程文档和自动化回归测试。

## 设计

1. 打开接口返回的链接后，等待新版“资质信息审核”、旧版“资质环节”或已经加载的“URL状态概览”之一出现。
2. 新版入口出现时，从“资质信息审核”标题向上寻找包含“查看”的最近卡片，仅点击该卡片内唯一可见的“查看”。
3. 旧版入口出现时继续使用既有 XPath/文本定位点击“资质环节”。
4. 点击后等待“URL状态概览”，并校验当前页面仍位于 `fkzhunru.baidu.com` 的旧版 `/flice` 或新版 `/newaudit` 应用路径。
5. 不硬编码新版 Hash 中的客户、流程、账户和签名等动态片段。

## 依赖
