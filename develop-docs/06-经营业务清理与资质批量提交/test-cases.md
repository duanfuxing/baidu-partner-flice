# 任务 6：测试用例

## 类型预检和删除

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T6-01 | 页面类型与输入类型一一匹配 | 预检通过，不删除目标类型 |
| T6-02 | 页面存在可删除的多余类型 | 生成删除计划并准确删除 |

| T6-09 | 删除确认弹窗名称不一致 | 取消删除并停止 |
| T6-10 | `--dry-run` | 只输出保留/删除/添加计划，不修改页面 |
