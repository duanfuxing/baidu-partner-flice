# 桌面 UI 视觉重构计划

## 目标

在不改变版本 `0.30.0` 业务流程的前提下，将桌面界面从系统原生工具样式重构为清晰、克制、适合业务人员使用的现代桌面应用。

## 范围

- 默认使用浅色专业后台主题，主色为百度蓝。
- 重构为左侧导航 + 右侧内容区。
- 首页只保留输入目录选择、验证摘要、运行选项和主操作。
- 验证结果使用统计卡片和结构化表格展示。
- 本次日志、历史日志使用独立页面。
- 登录、运行、成功、警告和错误状态使用明确的状态条与颜色。
- 保留目录必选、登录确认、安全取消、单 worker、历史日志等现有功能。
- Windows 和 macOS 使用一致的组件视觉。

## 设计原则

- 主任务路径优先：选择目录 → 查看验证结果 → 开始运行。
- 一屏一个主要动作，危险/取消操作弱化但可发现。
- 空状态不展示巨大的空黑表格，改为居中说明。
- 统计信息使用卡片，不把状态压缩到一行小字中。
- 日志使用等宽字体和深色背景，与业务信息区分。
- 颜色承担状态含义，但不以颜色作为唯一提示。

## 页面结构

1. **任务首页**
   - 产品标题、版本和当前状态。
   - 输入目录选择卡片。
   - 4 个验证统计卡片：公司、资质类型、资质、文件。
   - 验证结果表格或错误列表。
   - dry-run、截图选项与开始按钮。
2. **本次运行**
   - 当前阶段、状态提示、登录确认和取消。
   - 实时日志面板。
3. **历史日志**
   - 左侧历史任务列表。
   - 右侧日志详情。

## 验收标准

- [x] 首次打开时主路径和主要按钮清晰。
- [x] 浅色主题通过应用级组件实现，Windows 和 macOS 使用同一套视觉。
- [x] 未选择目录时展示友好的空状态。
- [x] 验证通过后统计卡和表格同步更新。
- [x] 验证失败时展示醒目的错误卡片。
- [x] 运行期间自动切换到本次运行页。
- [x] 登录确认和取消按钮只在相关状态出现或启用。
- [x] 历史日志浏览清晰且不影响当前任务。
- [x] 现有 66 项业务和安全测试全部通过。

## 完成记录

- 使用 CustomTkinter 重构桌面壳层、导航、卡片、状态标签、按钮和文本区域。
- 仅在验证结果表格中保留 ttk Treeview，并应用独立浅色样式。
- macOS Intel 冻结包构建成功，`--self-check` 通过，实际启动截图验收通过。
- Windows x64、macOS Apple Silicon 和 macOS Intel 将继续由 GitHub Actions 分平台构建。

## 不在范围内

- 修改百度页面自动化逻辑。
- 在线更新、账号管理或多用户系统。
- 动画框架和复杂视觉素材。
