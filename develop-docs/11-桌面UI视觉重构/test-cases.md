# 测试用例

## 初始状态

1. 启动后默认进入任务首页。
2. 输入目录为空，开始按钮不可用。
3. 统计卡显示 0，验证区显示选择目录提示。
4. 登录确认和取消按钮不可用。

## 校验状态

1. 校验中显示进度状态并禁用重复操作。
2. 校验成功显示四个统计卡和公司/类型表格。
3. 校验失败显示错误数量和完整错误列表。
4. 重新选择目录时清空上一次统计和结果。

## 运行状态

1. 开始运行后自动切换到本次运行页面。
2. 需要登录时显示蓝色提示和登录确认按钮。
3. 请求取消后显示等待当前公司结束的提示。
4. 成功、失败、busy 和取消使用不同状态文案。

## 日志

1. 本次日志使用等宽字体并自动滚动。
2. 历史日志列表可选择并展示详情。
3. 无历史日志时显示空状态。

## 回归

1. 目录必选、重新复核、单 worker 和取消行为不变。
2. 66 项现有测试继续通过。
3. PyInstaller 源码及冻结包 self-check 通过。

## 验证结果

- `pytest`：66 项通过。
- PyInstaller macOS Intel 应用包：构建通过。
- 冻结应用 `--self-check`：通过。
- 冻结应用启动：通过；浅色主题、侧栏、卡片、空状态和按钮禁用态显示正常。
- Windows x64 与 macOS Apple Silicon：由 GitHub Actions 对应平台完成最终构建验证。
