# 测试用例

- 单文件及多文件逐个上传，延迟预览成功。
- 成功响应但预览超时：仅上传一次，报回填异常。

- 明确 503 且无文件：有限重试；耗尽失败。
- 保存后文件数量减少或整个预览区域消失：禁止继续和送审。
