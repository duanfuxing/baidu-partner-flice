# 上传可视区域与主动自动保存

目标：上传前滚动至底部并保证当前卡片可操作；主动触发页面保存，避免遗漏监听或一次失焦未触发后一直等待。
范围：新版上传可视区域、举证填写与保存监听；不直接调用提交接口。
设计：监听先于填写和失焦；主动移入移出卡片并点击安全空白；无请求时最多触发三次，有请求在途时只等待响应，不重复提交；校验HTTP、业务状态、文件及举证内容。
步骤：实现滚动和保存协调；增加本地Chrome夹具覆盖无事件、迟到响应、业务错误、重复保护；相关回归。
依赖：现有Playwright。
验收：首轮事件丢失能恢复；慢响应仅一个请求；未保存或业务错误不得成功；滚动容器及页面底部可达。
不在范围内：发版、真实最终送审、直接拼接接口。

结果：实现完成。相关组合回归11项通过（含初始6项新场景），最终新增8项保存/滚动测试通过；保存仍走页面事件，未直接拼接或调用submitlice。未执行Windows真实页面验收，未提交或发布安装包。
