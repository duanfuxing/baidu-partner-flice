# 任务 3：测试用例

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T3-01 | 公司名精确搜索且唯一结果 | 提取 `custId` |

| T3-08 | 多家公司连续处理 | 单家公司失败不影响后续公司 |
