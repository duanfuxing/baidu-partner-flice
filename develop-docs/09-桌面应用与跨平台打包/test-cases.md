# 测试用例

## 输入目录与校验

1. 启动窗口时路径为空，“开始运行”不可用。
2. 取消目录选择时保持未选择状态。
3. 选择合法目录后展示公司、资质类型、资质数量和文件数量。
4. 选择不存在、空目录或格式错误目录时展示全部校验错误。
5. 重新选择目录后旧校验结果失效，必须重新校验。
6. 校验通过后输入发生变化，开始运行时重新校验并阻止无效输入。
7. 一次任务完成或失败后清空已选目录，下一次运行必须重新选择。

## 登录与运行

1. 登录有效时自动进入后续流程，不显示人工确认状态。
2. 登录失效时窗口展示提示并启用“我已完成登录”按钮。
3. 点击登录确认后保存状态并继续运行。
4. 浏览器、接口或页面流程异常时在窗口展示错误，日志保留原始业务错误。
5. 多家公司始终按单 worker 串行处理。
6. 窗口运行期间不可重复启动任务或重新选择目录。

## 日志

1. 每次运行创建新的日志文件。
2. 本次日志实时展示 INFO、WARNING 和 ERROR。
3. 历史日志按时间倒序列出并可查看内容。
4. 不存在日志目录时显示空状态。
5. worker 日志写入本次任务日志。

## 打包

1. Windows 产物双击启动且不弹控制台窗口。
2. macOS arm64 与 Intel `.app` 均可启动。
3. 冻结应用启动 worker 时不会递归启动主窗口。
4. 软件可定位 Playwright 驱动和系统 Chrome。
5. GitHub Actions 普通构建上传三个 artifact。
6. `v0.30.0` 标签构建创建 Release 并附加三个压缩包。

## 回归

1. `python main.py --input <目录>` 命令行入口继续可用。
2. 原输入解析、接口、页面和流程 6 测试继续通过。
3. 调度状态、最终提交去重和失败后继续下一家公司保持有效。
