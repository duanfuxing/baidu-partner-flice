# 验证场景

| 类别 | 场景 | 预期 | 结果 |
| --- | --- | --- | --- |
| 正常 | 检查当前项目说明、约定与旧版模块 | 明确旧版废弃，新版为有效流程 | 通过 |
| 回归 | 检查新版上传粒度及保存说明 | 每目录一卡片、文件逐张上传并保存 | 通过，与 `_upload_type_in`、`_save_qualification_card` 对照 |
| 边界 | 检查恢复建议的完成状态 | 明确为建议，未声称已支持断点续传或远端核对 | 通过 |
| 静态 | git diff --check | 无格式错误 | 通过 |

后续恢复机制需要本地 HTML / 模拟接口覆盖：响应迟到、响应丢失但保存成功、保存明确失败、上传成功但预览暂时不可用、页面刷新后已保存项恢复、同名不同内容文件、重复保存、业务拒绝、重试上限、最终送审结果未知。这些是后续验收建议，本任务不新增或执行相应运行测试。
