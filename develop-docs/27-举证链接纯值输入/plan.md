# 任务 27：举证链接纯值输入

## 目标与范围

`表单信息.txt` 支持直接保存举证链接值，无需字段名；空文件表示不提供举证链接。兼容已有带标签格式。

## 设计与步骤

1. 无已知字段标签时，将全文作为举证链接，复用 URL 空白清理和单斜杠修正规则。
2. 存在已知字段标签时，沿用旧格式解析及重复字段、错误行校验，避免混合格式被错误接受。
3. 增加纯值、空值、BOM、URL 冒号、重复资质目录和 JSON 持久化回归测试。
4. 更新输入说明并运行输入解析及应用测试。

## 依赖

依赖任务 1 的输入模型、任务 23 的新版可缺省字段支持；不增加依赖。

## 验收标准

- 纯链接和空文件均通过校验，编号、名称、有效期可缺省。
- 链接正确传入 evidenceUrl，多个缺省编号和名称的资质不触发重复校验。
- 旧格式仍可读取；文件存在性、数量、大小及旧版页面必填预检继续有效。
- 回归测试通过，不修改用户 input 资料。

## 不在范围内

不修改页面上传和送审逻辑，不运行真实提交，不打包发布。
