# 任务 22：兼容新版 URL 投放资质详情入口

## 状态

已完成详情页导航和旧版操作防护；新版流程 6 留待页面字段与交互确认后单独开发。

## 目标

兼容新版“URL状态概览”行内“查看”打开新标签页的行为，将后续页面切换到 `/newaudit#/lice/invest_lice_list/...` 投放资质详情页。

## 范围

- 保持按输入 URL 精确匹配概览表格行。
- 只点击匹配行“操作区”内的“查看”。
- 同时等待旧版原页详情和新版新标签页详情。
- 新版以受支持的 `invest_lice_list` 路由和“投放资质”区域共同判定成功。
- 将实际详情页返回给后续工作流。
- 新版流程 6 尚未适配时，在任何新增、删除、上传或提交前明确停止。

## 设计

1. 点击 URL 行“查看”前记录当前浏览器上下文中的页面集合。
2. 点击后轮询原页面及本次新增页面：
   - 旧版出现“行业资质”时返回原页面；
   - 新版出现“投放资质”且 URL 为 `/newaudit#/lice/invest_lice_list/...` 时返回新页面。
3. `WorkflowRunner` 使用返回页面继续执行，而不是继续持有概览页。
4. 新版详情页进入流程 6 前执行版本守卫。旧版经营业务定位器不能在新版 DOM 上运行。

- 任务 5 提供 URL 精确匹配和行内“查看”定位。
