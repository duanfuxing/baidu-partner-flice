# 任务 23：测试用例

## 入口与默认业务

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T23-01 | 详情页点击“新增资质” | 进入新版“新增投放资质”页面 |
| T23-02 | 同时存在产品和业务入口 | 只点击蓝色“新增业务资质” |
| T23-03 | 默认出现业务1–4 | 识别业务1为推广审查，业务2–4为待删除项 |
| T23-04 | 删除默认多余业务 | 按业务4、3、2顺序点击各自标签 `×` |
| T23-05 | 删除后业务重编号 | 每次重新扫描，不复用旧序号 |
| T23-06 | 默认业务无法确认或推广审查可删除状态异常 | 停止且不上传文件 |
| T23-07 | 输入缺少或重复“推广审查” | 页面修改前失败 |

## 新增业务和类型选择

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T23-08 | 处理推广审查 | 复用业务1，不点击新增业务 |
| T23-09 | 处理其他输入类型 | 每个类型各点击一次“新增业务资质” |
| T23-10 | 下拉框输入“三类” | 只接受显式映射的“三类医疗器械（不可个人，B）”唯一候选 |
| T23-11 | 候选不存在、重复或仅相似 | 不选择、不上传并停止当前公司 |
| T23-12 | 新增后业务序号变化 | 按经营业务名称重新定位 |

## 文件和补充资质

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T23-13 | 类型只有一张文件 | 使用业务自带上传表单，不创建补充资质 |
| T23-14 | 类型有两张文件 | 第一张用主表单，第二张用补充资质1 |
| T23-15 | 类型有三张文件 | 再点一次“新增补充资质”，第三张用补充资质2 |
| T23-16 | 一个资质目录有多张文件 | 每张占独立表单并复用该目录举证链接 |
| T23-17 | 多个资质目录各有文件 | 先按目录顺序、再按文件顺序展平 |
| T23-18 | 补充资质类型 | 保持页面默认“其它” |
| T23-19 | 上传控件一次选择多文件 | 禁止；每个表单只设置一张文件 |
| T23-20 | 不同业务均有多个文件 | 各业务独立创建补充资质，不串卡 |

## 自动保存和审核

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T23-21 | 文件上传触发 `submitlice` | 等待对应 HTTP 和业务成功后继续 |
| T23-22 | 举证链接非空 | 填写、移出输入框并等待独立 `submitlice` 成功，再回读 |
| T23-23 | 举证链接为空 | 不填写，不额外等待举证链接 `submitlice` |
| T23-24 | 新版输入仍含编号、名称、有效期 | 不填写、不回读、不校验这些旧版字段 |
| T23-25 | `submitlice` HTTP 非 200 | 当前公司停止，不继续其他业务 |
| T23-26 | `submitlice` HTTP 200 但 `status != 0` | 当前公司停止，不继续其他业务 |
| T23-27 | `submitlice` 返回非 JSON | 当前公司停止，不继续其他业务 |
| T23-28 | 上传响应成功但页面文件数不为一 | 当前文件失败 |
| T23-29 | 最终业务/文件集合不一致 | 不发起审核 |
| T23-30 | 最终提交关闭 | 不点击“发起审核” |
| T23-31 | 最终提交开启且全部校验成功 | 点击底部唯一“发起审核” |
| T23-32 | 出现“确认发起审核？” | 只在该弹窗内点击唯一“确定” |
| T23-33 | 审核接口失败 | 当前公司失败，不标记最终提交成功 |
| T23-34 | 多个业务卡片同时可见 | 文件、补充资质和举证链接仅操作当前业务容器 |
| T23-35 | 页面说明文字包含“推广审查”但业务1不是该类型 | 删除前失败，不删除业务2–4 |
| T23-36 | 经营业务候选异步出现 | 等待候选出现后唯一精确选择 |
| T23-37 | 同一类型多个资质目录且编号、名称缺省 | 最终结果和下次运行幂等匹配不发生键覆盖 |
| T23-38 | `submitall` 返回 201 且 `status == 0` | 最终提交失败，严格要求 HTTP 200 |
| T23-39 | Element UI 使用隐藏文件 input | 仍能识别表单并通过 `set_input_files` 上传 |
| T23-40 | 主表单与补充资质区位于业务卡不同子节点 | 业务容器覆盖两者，第二张文件可创建补充资质 |
| T23-41 | 业务1说明文字包含“推广审查”，经营业务值为其他类型 | 校验失败且不删除默认业务 |
| T23-42 | 最终成功后只修改举证链接 | 不命中已完成结果，重新进入调度 |
| T23-43 | 业务标签含状态 SVG 和明确关闭控件 | 仅点击明确关闭控件；没有明确控件时安全失败 |
| T23-44 | 上传完成后业务或表单被页面异步移除 | 最终集合校验失败，不调用 `submitall` |
| T23-45 | 页面出现其他域名、GET 或相似路径的保存响应 | 不得将其归属为当前 `submitlice`/`submitall` 成功响应 |
| T23-46 | 历史成功结果缺少 `input_fingerprint` | 不跳过公司，重新进入处理流程 |
