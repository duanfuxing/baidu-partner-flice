# 任务 25：任务中心输入目录缓存与浅色配色

## 状态

已完成。目录缓存、任务结束后保留目录和浅色配色均已接入；自动测试及 macOS 应用重建、启动检查通过。

## 目标

桌面应用记住任务中心上一次选择的输入根目录，下次启动自动回显；同时将桌面界面统一为灰白、白色与浅蓝配色。

## 范围与设计

- 缓存写入应用数据目录的 `cache/settings.json`，不写入项目或用户输入目录。
- 用户成功选择目录后立即原子保存规范化绝对路径。
- 应用启动时恢复仍然存在的目录；缓存损坏、字段异常或目录已删除时安全忽略。
- 恢复目录后不自动校验、不自动打开浏览器，也不改变“完成后执行全部提交”默认关闭的行为。
- 目录选择器优先以上次有效目录作为初始位置。
- 一次任务结束后保留目录，但清空旧验证报告，用户需重新验证才能再次运行。
- 应用使用灰白页面背景、白色卡片和浅蓝交互强调，侧边栏不再使用深色底。

## 实施步骤

1. 增加独立 GUI 设置读写模块及异常容错。
2. 接入桌面应用初始化、目录选择和任务完成状态。
3. 更新任务中心提示文案。
4. 调整全局界面配色并检查文字对比度。
5. 增加有效缓存、无效 JSON、目录失效及覆盖保存测试。
6. 运行完整测试，重新构建并启动 macOS `.app`。
