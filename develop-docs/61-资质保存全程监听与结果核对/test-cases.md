# 测试场景

| 类别 | 场景 | 预期 | 结果 |
| --- | --- | --- | --- |
| 正常 | 上传后主动保存 | 一次写入，验证响应和回填 | 通过 |
| 竞态 | 自动保存先于保存方法入口 | 使用本卡匹配成功响应，不重复调用 | 通过 |
| 竞态 | 自动保存请求进行中或填写举证时触发 | 等待匹配请求，不并发写入 | 通过 |
| 隔离 | 旧时间边界、不同业务/卡片、文件数量或举证不符 | 不误判成功 | 通过 |
| 异常 | HTTP 错误、status 非零、非 JSON | 停止，保留原业务失败阶段 | 通过 |
| 未知 | 响应丢失但详情已持久化 | 只读核对后通过，不重新保存 | 通过 |
| 未知 | 详情不符/不可读或写入仍在进行 | 不放行，不盲目重传 | 通过 |
| 回归 | 保存后遮罩、图片、字段回填 | 保留已有稳定性校验 | 通过 |
| 真实 | 未上传的下一资质目录 | 全部文件保存并重新打开核对，无最终送审 | 通过 |

新增：内部 crmid 映射成功、错误 URL 主记录/错误公司映射/缺少映射拒绝；回填后迟到写入覆盖拒绝；多文件第二次保存失败后禁止第三次上传。具体证据与验证边界见 [verification.md](verification.md)。
