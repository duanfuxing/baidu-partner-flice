# 业务标签动态定位修复

目标：修复0.30.12新增业务后等待全局“业务”文本nth(2)超时。
范围：新版业务标签扫描及切换/删除引用，不修改上传、搜索、输入或最终审核。
依据：用户日志中9个推广审查文件已上传保存，随后业务2切换失败；现有扫描保存全局正则匹配nth位置，标题/标签异步变化会使该位置消失或指向其他业务。
设计：一次读取可见业务名称，按精确业务名称生成动态定位器；同名标题和标签优先当前可见的首项；后续DOM变化不能切到其他编号。
步骤：复现列表移位超时和误选；改为精确名称定位；回归新增、切换和删除业务。
依赖：现有Playwright，无新增依赖。
验收：扫描后前方标题删除、插入、隐藏均仍点击业务2；目标真正缺失时报错而不点其他业务；现有业务映射/上传保存回归通过。
不在范围内：发版、真实业务修改、最终送审。
结果：已修复，4项复现用例修复后通过；14项业务和上传保存相关回归通过；最终可见定位写法额外复测4项定位和6项新增/删除/类型选择均通过。compileall和git diff --check通过。尚未执行当前Windows真实页面验收；已随任务51发布至0.30.14。
