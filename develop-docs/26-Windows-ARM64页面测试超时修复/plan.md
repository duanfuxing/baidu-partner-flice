# 任务 26：Windows ARM64 页面测试超时修复

## 状态

本地修复完成，等待重新触发的 GitHub Actions 四架构验证。

## 目标

修复 GitHub Actions Windows ARM64 runner 上页面夹具点击测试因仿真 Chrome 较慢而产生的偶发超时，恢复四架构安装包构建。

## 根因与设计

- 失败发生在测试阶段，并非 PyInstaller 或 Inno Setup。
- ARM64 Python 运行的 Playwright 浏览器为 `chrome-win64`，按钮已成功定位，但 2 秒内没有完成可操作性检查。
- 业务默认页面超时为 30 秒；失败用例人为压缩为 2 秒，不符合较慢的跨架构 CI 环境。
- 只将该端到端页面夹具的超时放宽到 10 秒，不改变生产流程的超时和业务逻辑。

## 实施步骤

1. 调整失败页面夹具的操作超时。
2. 本地重复运行失败用例并执行完整回归。
3. 提交并推送修复。
4. 重新触发 GitHub Actions，确认四架构矩阵通过。
